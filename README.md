# Sistema de Chamados

## O problema

Times de automação, processos e dados recebem pedidos de vários setores, quase sempre por conversas soltas, sem registro formal. Sem esse registro, os pedidos se perdem, a priorização vira adivinhação e o time não consegue demonstrar o esforço e as entregas que realizou.

Este sistema centraliza os pedidos em chamados e registra cada mudança de status: quem abriu, quem atendeu, quando e quanto tempo levou. Com isso, o líder acompanha o andamento sem cobrar pessoa por pessoa, e o time passa a ter números para mostrar o próprio trabalho.
